# Mẫu thiết kế kiểm tra đánh giá

## 1. Thông tin

- Môn/lớp/chủ đề:
- Thời lượng:
- Phạm vi nội dung:
- Hình thức:
- Tài liệu/yêu cầu cần đạt làm căn cứ:

## 2. Bảng đặc tả

| Nội dung/đơn vị kiến thức | Yêu cầu cần đạt | Nhận biết | Thông hiểu | Vận dụng | Tổng |
|---|---|---:|---:|---:|---:|
| Chủ đề 1 | | | | | |
| Chủ đề 2 | | | | | |
| Tổng | | | | | |

Điền số câu/điểm theo cấu trúc đề đã thống nhất. Không mặc định tỷ lệ mức độ nếu người dùng chưa yêu cầu hoặc chưa có quy định áp dụng.

## 3. Đề kiểm tra

- Hướng dẫn làm bài.
- Câu hỏi đánh số liên tục.
- Nêu rõ dạng câu hỏi và điểm.
- Tránh câu mơ hồ, đánh đố hoặc phụ thuộc kiến thức ngoài phạm vi.

## 4. Đáp án và hướng dẫn chấm

- Đáp án chính xác.
- Lời giải/giải thích ngắn.
- Điểm từng ý.
- Chấp nhận phương án tương đương nếu hợp lý.
- Rubric cho sản phẩm/thực hành: tiêu chí, mức đạt, minh chứng.

## 5. Rà soát chất lượng

- Bao phủ yêu cầu cần đạt?
- Đúng nội dung đã học?
- Tổng điểm và thời lượng hợp lý?
- Có câu trùng lặp hoặc nhiều cách hiểu?
- Đáp án có kiểm chứng?
- Định dạng có lỗi?
